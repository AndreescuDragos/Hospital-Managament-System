# Hospital Management System

Hospital Management System is a desktop CRUD application built with **Java (Swing)**, **JDBC**, and **MySQL**.  
It manages patients, staff, lab tests, treatments, and inventory, providing efficient access for medical administration.

---

## 🚀 Features
- CRUD for patients, staff, tests, treatments, and inventory  
- Swing-based desktop interface  
- MySQL database integration  

---

## ▶️ Run
1. Import `management_system.sql` into MySQL (create database `management_system`).  
2. Update DB connection in `config.properties` (URL, user, password).  
3. Run the app:
  dist/HospitalManagementSystem.jar
